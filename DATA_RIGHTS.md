# Data rights and trace transformation

Source: [Open-source Cache Dataset](https://github.com/cacheMon/cache_dataset), curated and converted by Juncheng Yang. Its License section explicitly places this work under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Original source: Dushyanth Narayanan, Austin Donnelly and Antony Rowstron, *Write Off-Loading: Practical Power Management for Enterprise Storage*, FAST 2008, [paper](https://www.usenix.org/legacy/event/fast08/tech/full_papers/narayanan/narayanan.pdf). Attribute the collection and original work; no endorsement is implied.

The source describes enterprise block-I/O traces from February 2007. The README summary lists thirteen traces, while the observed converted OracleGeneral folder lists fourteen objects. We preserve that mismatch and select six from the actual listing by displayed size before reading values. No claim about the complete original collection or its published energy results follows.

Modifications: retain each selected file's first 200,000 request records; replace opaque eight-byte object tokens with ordinal IDs in order of first appearance; remove per-request clock, size and future fields; simulate authored equal-object LRU capacities and calculate forecasts. The ordered public prefixes are transformed recorded data, not a synthetic workload. They support exact cache replay while complete compressed sources remain private. This is a documented data transformation, not an anonymity guarantee.

The [official format reader](https://github.com/1a1a11a/libCacheSim/blob/develop/libCacheSim/traceReader/customizedReader/oracle/oracleGeneralBin.h), inspected Git blob 6cfaf0b87c7a17b1458428a57d85b3e3002fe2f9, confirms 24-byte records and field offsets. Object equality uses opaque bytes 4:12, so the analysis does not infer numeric byte order. Bytes 16:24 contain future access and are never decoded. Aggregate clock/size metadata use a recorded little-endian working interpretation, without asserted calendar-time units. No per-request clocks, raw addresses, host/client/IP details, sizes or future-access values are published.

Our MIT license covers original code. CC BY 4.0 continues to apply to source-derived request sequences. No private personal/clinical data, credentials, package archives or formal-publication drafts are included. No account, key, cloud instance or paid execution was used.
